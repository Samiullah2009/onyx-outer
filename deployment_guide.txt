1. WHAT CHANGED FROM THE ORIGINAL BUILD
================================================================

The original site was built for Apache + MySQL (InfinityFree hosting).
This version has been adapted for Vercel serverless PHP:

  MySQL → PostgreSQL (Vercel Neon Postgres)
    - ON DUPLICATE KEY UPDATE → ON CONFLICT ... DO UPDATE
    - ORDER BY RAND()         → ORDER BY RANDOM()
    - AUTO_INCREMENT          → SERIAL
    - INT/TINYINT(1)          → INTEGER/SMALLINT

  Sessions → Database-backed (required on Vercel serverless)
    - PHP file sessions don't persist across Vercel function instances
    - All sessions stored in the `php_sessions` table

  Rate limiting → Database-backed
    - File-based /tmp rate limiting replaced with `rate_limit_cache` table

  File uploads → Disabled (Vercel filesystem is read-only)
    - Use "Add Image URL" in Admin Panel instead
    - Paste Unsplash URLs, Cloudinary URLs, or any public CDN link

4. MANUAL DEPLOYMENT (STEP-BY-STEP)
================================================================

STEP 1 — Push to GitHub
  a. Create a new GitHub repository at https://github.com/new
     Name: onyx-outer  (or any name you like)
     Visibility: Private recommended
  b. In terminal, inside the php-site/ folder:
       git init
       git add .
       git commit -m "Initial deployment"
       git branch -M main
       git remote add origin https://github.com/YOUR_USERNAME/onyx-outer.git
       git push -u origin main

STEP 2 — Import to Vercel
  a. Go to https://vercel.com/new
  b. Click "Import Git Repository"
  c. Select your onyx-outer repository
  d. Framework Preset: "Other" (do NOT select PHP — vercel.json handles it)
  e. Click "Deploy"
  f. The first deploy will fail — that's okay, we need to add env vars first

STEP 3 — Create Vercel Postgres Database
  a. In your Vercel project dashboard, go to "Storage" tab
  b. Click "Create Database"
  c. Choose "Neon Serverless Postgres"
  d. Name it: onyx-outer-db
  e. Region: Choose closest to your users
  f. Click "Create"
  g. Vercel automatically adds POSTGRES_URL and PGHOST etc. to your project

STEP 4 — Add Environment Variables
  In Vercel → Project → Settings → Environment Variables, add:

    SITE_URL          = https://your-project.vercel.app
    ADMIN_USERNAME    = phantom
    ADMIN_PASSWORD_HASH = $2y$12$IpBCqL6I820Om/m7o/d.ce5LgSDdwQQc3l6QYxfVsuvHQ1Is6HWH2
    SETUP_KEY         = onyx_setup_2025_secret

  (The Postgres variables are added automatically by Vercel Storage)

STEP 5 — Redeploy
  a. Go to Deployments tab → click the three dots on latest → Redeploy

STEP 6 — Run Database Setup
  a. Visit: https://your-project.vercel.app/setup.php?key=onyx_setup_2025_secret
  b. You should see "Database setup complete!"
  c. All tables and default data are now installed

STEP 7 — Log In
  a. Visit: https://your-project.vercel.app/admin/login.php
  b. Username: phantom

================================================================

The database setup runs via /setup.php. It is idempotent — safe to
run multiple times. Tables created:

  php_sessions        — Database-backed PHP sessions (Vercel compatible)

  categories          — Product categories

  product_images      — Product images (URLs)
  reviews             — Customer testimonials

  social_links        — Social media URLs
  chat_context        — AI chatbot context cache
  admin_sessions      — Extra security layer
  trending_log        — Trending rotation history
  subscribers         — Newsletter subscribers

11. IMPORTANT LIMITATIONS ON VERCEL
================================================================

FILE UPLOADS
  The Vercel filesystem is read-only (except /tmp which is temporary).
  Uploaded files in /tmp are LOST after the serverless function finishes.

  → Solution: Always use "Add Image URL" in the Admin Panel.
  → Use Cloudinary (free tier) for persistent image hosting:
       https://cloudinary.com — upload images there, paste URLs here.
  → Or use any public image CDN or Unsplash.

SESSION PERSISTENCE
  Vercel serverless functions are stateless. Sessions are now stored
  in the PostgreSQL database so they persist correctly.

COLD STARTS
  First request after inactivity may be ~1-2 seconds slower.
  This is normal for serverless PHP.

EXECUTION TIME
  Vercel limits serverless function execution to 10 seconds (Hobby plan).
  The AI chatbot endpoint may be slow for long conversations.
  Upgrade to Vercel Pro for 60-second limit.

12. TROUBLESHOOTING
================================================================

PROBLEM: "Database connection failed"
  → Check that Vercel Postgres is linked to your project
  → Verify POSTGRES_URL env var is set
  → Redeploy after adding env vars

PROBLEM: "403 Forbidden" on setup.php
  → Add ?key=onyx_setup_2025_secret to the URL
  → Or check SETUP_KEY env var matches

PROBLEM: Admin login not working
  → Clear cookies and try again
  → Check ADMIN_USERNAME and ADMIN_PASSWORD_HASH env vars
  → Default password for the pre-set hash: ms28200938879

PROBLEM: Session keeps logging out
  → Check php_sessions table exists (run setup.php again)
  → Verify POSTGRES_URL is correct

PROBLEM: Product images not showing
  → Make sure image URLs are publicly accessible
  → Use full https:// URLs (not relative paths)

PROBLEM: AI chatbot not responding
  → Add your Anthropic API key in Admin → API Keys
  → Check it starts with "sk-ant-"

PROBLEM: Vercel deployment failing
  → Check the Build Logs in Vercel dashboard
  → Ensure vercel.json is in the repository root
  → Verify PHP function paths in vercel.json match actual file paths

13. MIGRATING TO A CUSTOM DOMAIN
================================================================

  1. Buy a domain (Namecheap, GoDaddy, Cloudflare, etc.)
  2. In Vercel: Project → Settings → Domains
  3. Click "Add" and enter your domain
  4. Update your domain's DNS:
       Type: CNAME
       Name: www (or @)
       Value: cname.vercel-dns.com
  5. Wait 5-60 minutes for DNS propagation
  6. Update SITE_URL env var to your custom domain
  7. Redeploy
